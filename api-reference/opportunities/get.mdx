Retrieve the full details of a specific opportunity, including its current pipeline stage, the Rhombus Account Executive and Solutions Engineer assigned to it, and the projected installation date. Use this endpoint to sync pipeline status into your CRM or display deal progress in your internal tooling.

## Request

```http
GET https://api.ecosystem.rhmbs.app/v1/opportunities/{id}
```

### Path Parameters

<ParamField path="id" type="string" required>
  The unique opportunity ID returned in the `id` field when the opportunity was created (e.g., `opp_01hx9z3kqe4vb8mnpj7wtrcfd2`).
</ParamField>

## Example Request

<CodeGroup>

```bash cURL
curl --request GET \
  --url https://api.ecosystem.rhmbs.app/v1/opportunities/opp_01hx9z3kqe4vb8mnpj7wtrcfd2 \
  --header 'Authorization: Bearer <api-key>'
```

```python Python
import requests

opportunity_id = "opp_01hx9z3kqe4vb8mnpj7wtrcfd2"
url = f"https://api.ecosystem.rhmbs.app/v1/opportunities/{opportunity_id}"
headers = {
    "Authorization": "Bearer <api-key>",
}

response = requests.get(url, headers=headers)
print(response.json())
```

</CodeGroup>

## Response

A successful request returns `200 OK` with the full opportunity object.

### Response Fields

<ResponseField name="id" type="string">
  Unique identifier for the opportunity (UUID).
</ResponseField>

<ResponseField name="name" type="string">
  Descriptive name of the opportunity.
</ResponseField>

<ResponseField name="stage" type="string">
  Current pipeline stage. Possible values: `submitted`, `in_triage`, `ae_assigned`, `se_engaged`, `pending_installation`, `scheduled`, `installed`, `closed_lost`.
</ResponseField>

<ResponseField name="customer" type="object">

      Email address of the primary contact.

    <ResponseField name="contact_phone" type="string">
      Phone number of the primary contact.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="location" type="object">
  Physical address of the installation site.

  <Expandable title="location fields">

      Street address of the installation site.
    </ResponseField>

    <ResponseField name="city" type="string">
      City of the installation site.

      Two-letter state or province code.

    <ResponseField name="zip" type="string">

<ResponseField name="assigned_se" type="null | object">

  <Expandable title="assigned_se fields">
    <ResponseField name="id" type="string">
      Unique identifier of the SE.
    </ResponseField>

    <ResponseField name="name" type="string">
      Full name of the assigned SE.

    <ResponseField name="email" type="string">
      Work email address of the assigned SE.

<ResponseField name="install_partner" type="null | object">

  <Expandable title="install_partner fields">

<ResponseField name="projected_install_date" type="null | string">

<ResponseField name="created_at" type="string">

</ResponseField>

<ResponseField name="updated_at" type="string">

## Error Responses

| Status | Code | Description |
|--------|------|-------------|
| `401 Unauthorized` | `unauthorized` | The API key is missing, expired, or invalid. Check that your `Authorization` header is correctly formatted. |
| `404 Not Found` | `not_found` | No opportunity with the given ID exists in your partner account. Verify the ID and that the opportunity belongs to your account. |
